# TenFind — 成長株スクリーナー

企業の成長性や収益性などを確認できる、ブラウザー向けのサンプルアプリです。銘柄名・数値・スコアはすべて架空のデモデータで、投資判断に利用できる実データではありません。

## 起動方法

`index.html` をブラウザーで開いてください。ビルドやパッケージのインストールは不要です。

## ファイル構成

- `index.html` — 画面とコンテンツ
- `styles.css` — レイアウトとレスポンシブデザイン
- `app.js` — サンプル銘柄、スコア計算、検索・並び替え・ウォッチリスト

検索欄では銘柄名・コード・業種で絞り込めます。銘柄の行を選ぶと分析が表示され、星印でウォッチリストに追加できます。
