# TenFind — 成長株スクリーナー

企業の成長性や収益性などを確認できる、ブラウザー向けのサンプルアプリです。掲載する会社名・証券コードは実在する東証グロース上場企業のものです。一方、売上成長率・利益率・PER・時価総額・スコア・分析コメントはすべて架空のデモデータで、実際の企業データではありません。投資判断には利用しないでください。

## 起動方法

`index.html` をブラウザーで開いてください。ビルドやパッケージのインストールは不要です。

## ファイル構成

- `index.html` — 画面とコンテンツ
- `styles.css` — レイアウトとレスポンシブデザイン
- `app.js` — 掲載銘柄、サンプルスコア計算、検索・並び替え・ウォッチリスト

検索欄では銘柄名・コード・業種で絞り込めます。銘柄の行を選ぶと分析が表示され、星印でウォッチリストに追加できます。
